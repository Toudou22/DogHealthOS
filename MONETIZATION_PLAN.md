```

             │ • Static Breed Math │               │ • Firestore Quota   │
             │ • Local 62 Photos   │               │   Check per 24 hrs  │
             │ • 0 Gemini API Load │               │ • Token Counter Log │
             └─────────────────────┘               └──────────┬──────────┘
                                                              │
                                            ┌─────────────────┴─────────────────┐
                                            ▼                                   ▼
                                    Free Account Quota                  Pro / Breeder Plan
                                    • 3 Diagnostics / day               • Unlimited Access
                                    • 1 NutriChef / day                 • Priority API Queue
                                    • HTTP 429 Graceful Fallback        • Vector PDF Exports
```

1. **Authentication Gate for Heavy Generative Endpoints:**
   Visitors cannot trigger server-side LLM diagnostic requests without authenticating via Firebase.
2. **Server-Side Graceful Fallback Handling:**
   When the Gemini API quota returns a `429 Too Many Requests` status, the server serves pre-verified, veterinary-certified clinical fallback responses. This maintains full app functionality with zero broken UI states.
3. **100% Local Image Fallback Strategy:**
   All 62 mapped core breeds use local lightweight assets in `/public/dog-images/`, preventing runaway image-generation API charges.
